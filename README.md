# ステガノグラフィ研究プロジェクト

## 概要

このプロジェクトは、画像に秘密情報を隠蔽する**ステガノグラフィ**技術の研究・実装を行っています。アダマール変換とドブルイン系列を用いた2つの異なる埋め込み手法を実装し、その性能を比較評価しています。

## 実装されている手法

### 1. ビット反転埋め込み手法
- **概要**: 周波数領域の係数の特定ビットを反転して秘密情報を埋め込む
- **特徴**: 
  - 1bitまたは2bit単位での埋め込み
  - 複数の埋め込み領域（矩形領域、四隅、全体）に対応
  - 異なるビット位置での埋め込み実験

### 2. 閾値調整埋め込み手法
- **概要**: 論文で紹介された手法で、閾値に基づいて係数行列を調整
- **特徴**:
  - 閾値（TH）と調整係数（IF）による制御
  - 複数の秘密画像サイズに対応
  - 様々なテスト画像での評価

## 使用する変換行列

### 1. 再帰的アダマール行列（Sylvester Hadamard）
- 再帰的に生成されるアダマール行列
- サイズ: 2^n × 2^n

### 2. 交番数順アダマール行列（Walsh Hadamard）
- 交番数（Walsh function）の順序で並べられたアダマール行列
- より自然な周波数順序

### 3. ドブルイン行列
- ドブルイン系列に基づいて並び替えられたアダマール行列
- ランダム性の高い変換

## 実験設定

### カバー画像
- サイズ: 256×256ピクセル
- 形式: グレースケールBMP
- 主な画像: Lenna

### 秘密画像
- サイズ: 32×32, 64×64, 128×128, 256×256ピクセル
- 形式: グレースケールBMP
- テスト画像: 標準画像（Barbara, Airplane, Boat, Cameraman, Mandrill等）

### 評価指標
- **PSNR（Peak Signal-to-Noise Ratio）**: 画像品質の評価
- 埋め込み容量と画質のトレードオフ分析

## ビルド方法

### 必要な環境
- C++17対応コンパイラ
- CMake 3.10以上
- OpenCV ライブラリ
- Eigen3 ライブラリ（プロジェクト内に含まれています）

### ビルド手順
```bash
mkdir build
cd build
cmake ..
make
```

### 実行
```bash
./steganography_project
```

## 出力結果

### ファイル命名規則
- `stego_`: ステゴ画像（秘密情報が埋め込まれた画像）
- `secret_`: 抽出された秘密画像
- `b0`, `b1`, ...: 埋め込みビット位置
- PSNR値: 画像品質指標（dB）

### 結果の解釈
- 高いPSNR値 = より良い画質
- 埋め込みビット位置によって画質が変化
- 異なる変換行列による性能比較が可能

## 研究の意義

このプロジェクトは以下の研究課題に取り組んでいます：

1. **変換行列の選択がステガノグラフィ性能に与える影響**
2. **埋め込み領域とビット位置の最適化**
3. **埋め込み容量と画質のトレードオフ分析**
4. **異なる秘密画像サイズでの性能評価**
